# Generated Pendelhaven surface textures

These original project assets were created with the built-in OpenAI image-generation tool and are used as repeating albedo maps by the Three.js material enhancement pass.

- `pendelhaven-stone-v1.png` — seamless worn brown-gray sandstone and damp cellar masonry, flat neutral lighting, no baked directional shadow
- `pendelhaven-oak-v1.png` — seamless aged dark oak planks with restrained hand-oiled wear, flat neutral lighting, no baked directional shadow

Both prompts requested a realistic PBR-style albedo texture, orthographic square coverage, seamless edges, no focal object, and no text, symbols, logos, or watermark. They contain no original Rose COG artwork.
